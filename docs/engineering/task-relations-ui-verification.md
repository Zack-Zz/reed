## 可操作范围

- 以任意任务为起点向右展开拆分树；切换起点、返回上级、展开收起、缩放、适应视图及鼠标／键盘平移。
- 节点展示任务类型、独立生命周期、来源和关联资源数；点击打开共用详情抽屉。
- 节点“＋”新增独立待办任务或关联已有任务；区分拆分、普通关联、前置依赖和明确确认的必要交付。
- 抽屉关闭及导航返回保留画布上下文；查看关系不 checkout、不派发 Agent、不改变任务状态。
- 示例族为明确请求后的增量模拟数据；重复查看幂等，既有任务与草稿保留。
