# 统一任务前端：实现与验证记录

日期：2026-10-30（Asia/Shanghai）。范围：共享正式前端与本地模拟适配，不是 Core 业务或真实宿主验收。

## 实现范围

- Web 与 Tauri 继续装配同一 `WorkbenchRoot`、组件、样式与模拟 runtime；没有新增桌面页面副本。
- 任务类型与待办／处理中／评审中／已完成／已归档分开；默认无内部流程，看板仍四列。
- 通用详情包含目标、必要验收条件、产物版本、处理记录及资料／会话／分支关联。
- 提交任务评审固定范围、材料、真实结果和来源；逐项接受后形成任务完成决定。
- 内部步骤接受不自动提交或完成 Task；可明确合并内部确认，但必要实际工作仍须满足。
- 归档只允许已完成；恢复回已完成；理由重开回处理中并保留原完成决定和证据。
- 保存使用 version 3 模拟草稿，保留原 `reed-demo-v2` 键并兼容读取 version 2。
  旧阶段完成不补造任务级验收，原内容及状态历史保留，缺完成依据的旧完成／归档项提示核查。

业务规则仍由 `src/mock` 提供，通过 runtime services 注入页面；临时呈现结构不是正式 Core／通信契约。
Rust、生成协议、壳端原生代码和真实连接能力未在本轮修改。
